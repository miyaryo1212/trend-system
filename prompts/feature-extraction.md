## 前回レポート (既出トピックの除外用)

以下は前回レポートの内容です。**ここで既に扱われているトピック・機能は、原則として
今回の抽出に含めないでください。**

```
{{PREVIOUS_REPORT}}
```

## 出力ルール

- 箇条書きのみ。前置き・補足・まとめは一切不要
- 各行は `- 名前: 簡潔な説明(1行以内)` の形式
- **前回レポートで既出のトピックは除外する**。ただし「本日新たに具体的な進展
  (新バージョン公開・新事実・新数値など) があった」場合のみ、その新規分に焦点を
  当てて含めてよい (例: 前回「Xを発表」→ 今回「Xが正式版リリース」は可)。
- 「サイトマップでページが更新された」だけで内容が新規でないものは含めない。
  ページ更新 ≠ 新トピック。実際に新しい情報があるか `WebFetch` で確認すること。
- 真に新規のトピックが無い場合は `なし` とだけ出力 (無理に既出ネタで埋めない)
- 出力先: `{{FEATURES_PATH}}` にテキストファイルとして Write ツールで書き出すこと
